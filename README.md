# PowerBI-Sales-Dashboard
This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales trends, product performance, regional sales, and salesperson performance using a realistic sales dataset.
## Project Objectives 
To build an interactive Power BI dashboard that analyses sales performance, tracks key business metrics, and provides actionable insights through dynamic visualisations and interactive filtering.

## Business Questions (KPIs)

This dashboard is designed to answer the following business questions:

### Executive Dashboard
- What is the total sales revenue?
- How many orders were placed?
- What is the total quantity of products sold?
- What is the average sales value per order?
- How have sales changed over time?

### Product Performance Dashboard
- Which products generate the highest sales?
- Which product category contributes the most to total sales?
- How are sales distributed across different product categories?
- What are the detailed sales records for each product?

### Regional & Salesperson Performance Dashboard
- Which region has the highest sales?
- Which salesperson achieved the highest sales?
- How does sales performance vary by region?
- What are the detailed sales transactions by region and salesperson?

## Process

1. Collected and prepared a 200-row sales dataset in Excel.
2. Imported the dataset into Power BI Desktop.
3. Created DAX measures for Total Sales, Total Orders, Total Quantity, and Average Sales.
4. Built three interactive dashboard pages with charts, KPI cards, tables, and slicers.
5. Applied formatting, colours, and titles for a professional layout.
6. Published the completed project to GitHub with the dataset, Power BI file, screenshots, and documentation.

## Project Insights

- Electronics generated the highest sales among all product categories.
- Sales performance varied across different regions and salespersons.
- A small number of products contributed significantly to overall sales.
- Interactive slicers enabled users to analyse sales by region, category, salesperson, and date.
- KPI cards provided a quick overview of key sales metrics.

## Conclusion

This Power BI dashboard effectively visualises sales performance using interactive charts, KPI cards, tables, and slicers. It enables users to monitor sales trends, evaluate product and regional performance, and make data-driven decisions. The project demonstrates practical skills in data visualisation, DAX, dashboard design, and business intelligence using Microsoft Power BI.
